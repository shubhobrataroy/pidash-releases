## 🖥 What is Pi Dash?

**Pi Dash** is a remote Linux management dashboard that allows you to monitor and control Linux systems (including Raspberry Pi) over SSH from a simple UI.

The desktop version brings the same monitoring and management capabilities to **Windows, macOS, and Linux**.

---

✔ No source code

---

## 🚀 Features

- System monitoring (CPU, RAM, temperature, uptime)
- Process listing and termination
- Power actions (shutdown, reboot)
- Disk and storage management
- Service management
- Debian package management
- System update & upgrade
- Docker container support
- Hardware information
- Custom SSH command execution

All operations are performed securely over **SSH**.

## 🔐 Connectivity

- Requires SSH access to the target Linux machine
- Supports password and key-based authentication
- No background services required on the target system

## 🛡 Privacy

Pi Dash communicates **only via SSH** with your own machines.
